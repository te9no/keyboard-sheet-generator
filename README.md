# Keyboard Sheet Generator — te9no fork

[公開サイト](https://te9no.github.io/keyboard-sheet-generator/) · [フォーク元](https://github.com/alektor-diy/keyboard-sheet-generator)

このフォークは、元のアプリに単体・A4面付けSVG出力、画像追加、モノクロ帯6種類を追加しています。元作者のMITライセンスと著作権表示を保持しています。

キーボード展示会やミートアップで、キーボードの横に置く紹介シートを作成・印刷するためのWebアプリです。

キーボード名、オーナー名、スイッチ、キーキャップ、試し打ちや撮影の可否、紹介文を入力すると、A6横サイズの紹介カードを作成できます。

## 利用する人へ

### できること

- 「基本デザイン」、「ながれキー」、「天キーVol.12」、「Touch,Type＆Talkey」のテンプレート選択
- 入力内容のリアルタイムプレビュー
- 複数キーボード分のシート作成、編集、複製、削除
- 印刷対象の個別選択、すべて選択、すべて解除
- イベントロゴ表示のオン・オフ切り替え
- 編集中のシートのSVGダウンロード（ロゴ画像を埋め込み、文字・罫線はベクターで保存）
- A4への4面付け印刷
- 手書き用の空欄シート印刷
- 自由記述欄の印刷基準による自動改行

### 使い方

1. テンプレートを選択します。
2. キーボードの情報を入力します。
3. 試し打ちと撮影・SNS投稿の可否を選択します。
4. プレビューを確認します。
5. 必要に応じて、A4面付け・空欄シートを印刷します。

入力内容は利用しているブラウザの `localStorage` に保存されます。外部サーバーへの送信、アカウント登録、クラウド同期は行いません。別のブラウザや別の端末ではデータは共有されません。

自由記入欄とスペック欄に文字数制限は設けていません。印刷時に読みやすくなるよう、自由記入欄は5行以内を目安に調整し、印刷プレビューで全体を確認してください。

## GitHub Pagesで公開する

このアプリはHTML、CSS、Vanilla JavaScriptだけで構成されているため、ビルドやサーバーは必要ありません。

1. このリポジトリをGitHubへpushします。
2. GitHubリポジトリの `Settings` → `Pages` を開きます。
3. `Source` で `Deploy from a branch` を選択します。
4. 公開するブランチに `main`、フォルダに `/(root)` を指定して保存します。
5. 表示されたGitHub PagesのURLを開きます。

更新を公開する場合は、公開元ブランチへ変更をpushしてください。GitHub Pagesが自動的に再デプロイします。

## ローカルで確認する

リポジトリを取得したあと、`index.html` をChrome、Edge、Firefoxなどのモダンブラウザで直接開いてください。開発用サーバーやnpmのインストールは不要です。

印刷結果を確認するときは、ブラウザの印刷画面で倍率100%、A4横、余白なしを推奨します。紹介カードはプリンターの印刷不能領域を考慮してA4へ4面付けされます。

変更履歴は [CHANGELOG.md](CHANGELOG.md) に記録しています。

## 開発者・テンプレート改修者へ

### ファイル構成

```text
index.html
css/
  app.css             通常画面
  print.css           印刷の外枠・面付け
  card-shared.css     カード内部の共通レイアウト
  logo.css            ながれキー・天キーのブランド表示
js/
  app.js              入力、保存、シート管理
  card.js             プレビュー・印刷で共通利用するカード生成
  print.js            印刷モード切り替え
  storage.js          localStorage保存
  assets/
  nagare-key/logo.png ながれキーのロゴ
  Touch-Type-Talkey/ttt_logo.png TTTのロゴ
```

### モノクロ帯

「帯のデザイン」の見本を押すと、スラッシュ・チェッカー・ドット・サーキット・シェブロン・バーコードの6種類から選べます。「テンプレート標準」と「帯なし」も選択できます。白黒の図形で描画するため、グレーの濃淡に頼らず、背景グラフィックを無効にした印刷にも対応します。変更するのは上端の帯のみです。

帯の設定はシートごとに保存・複製・JSON入出力されます。4面付けは保存済みの設定を使うので、変更後は「シートを保存」を押してください。空欄印刷には現在選択中の帯を使います。既存データは「テンプレート標準」のまま読み込みます。

### 画像の追加

編集フォームの「画像・ロゴ・QRコード」から、PNG・JPEG・WebPを1シートにつき6枚まで追加できます。「名前の横」「右下（QRなど）」「中央（横長画像）」で配置し、横位置・縦位置・幅をカード全体に対する割合（%）で調整します。縦横比と透明部分を維持し、画像は文字の上に重ねて表示します。プレビューを見ながら文字やイベントロゴと重ならない位置に調整してください。QRコードは画像ファイルとして追加します。

画像は最大辺1024 pxに縮小してブラウザ内に保存します。画像ごとに削除でき、シート保存・複製・JSONエクスポート／インポートでも保持されます。ブラウザの保存容量が不足すると画面下部に案内を表示するので、JSONをエクスポートするか画像を減らしてください。画像付きのシートを4面付けに使う場合は、先に「シートを保存」を押してください。

印刷・単体SVG・4面付けSVGにも画像を反映し、SVGには画像データを埋め込みます。空欄シートの印刷には追加画像を含めません。

### SVG出力

プレビュー下の「SVGで保存」から、未保存の入力内容も含めて1枚のSVGをダウンロードできます。サイズは現在のプレビュー・A4面付けカードと同じ139.5 × 96 mmです。選択中のテンプレート、イベントロゴの表示設定、改行、特徴タグを反映します。ロゴはPNGを埋め込み、外部ファイルへの参照は含めません。文字は編集可能なSVGテキストとして保持するため、別の環境で開く場合はフォントによって字形が変わることがあります。

「A4・4面付けSVGを作成」では、作成済みシートの選択分を一覧順に左上・右上・左下・右下へ配置します。A4横（297 × 210 mm）、外周余白7 mm、カード間4 mmで、1枚あたり139.5 × 96 mmです。5枚以上は4枚ごとにページを分け、端数の枠は空白にします。生成後のページ別リンクから各SVGを保存してください。編集内容は先に「シートを保存」で反映してください。

SVGの生成は `js/svg.js` が共通カードのレイアウトを測定して行います。テンプレート上端のアクセントを変更・追加した場合は、このファイルのグラデーション定義も更新してください。ロゴ画像を差し替える場合は、直接ファイルを開いた環境用の `js/svg-assets.js` の対応するdata URLも元PNGから再生成してください。このファイルは `file:` でのSVG出力時のみ読み込まれます。

### 新しいテンプレートを追加する場合

ユーザーが画面上で自由にテンプレートを作成する機能はありません。新しいイベント向けテンプレートをコードで追加する場合は、主に以下を変更します。

- `index.html`：テンプレート選択肢
- `js/app.js`：テンプレート名や選択状態
- `js/card.js`：ロゴやフッターなど、カード内容の差分
- `css/`：テンプレート固有の色、ロゴ位置、装飾
- `assets/`：ロゴ画像

プレビューと印刷は `js/card.js` の共通カード生成処理を使用します。カード内部のサイズや余白を調整するときは、まず `css/card-shared.css` を確認してください。
